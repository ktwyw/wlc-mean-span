# Data files

All files in this folder were generated by the code in `code/`. Licence: CC BY 4.0 (`../DATA_LICENSE.md`). Lengths are in
units of the persistence length `p`; `lambda = L/p`; `F = X/p` is the
dimensionless mean span.

## Primary results

| File | Produced by | Contents |
|---|---|---|
| `wlc_mean_span_reference.csv` | `build_reference_curve.py` | The reference curve at 67 nodes (0.01 to 1e5): finite-order spectral values `F_m32`..`F_m96` (ordered-Schur stable subspace, alias-corrected inversion with A=12), continuum extrapolation `F_continuum`, two alternative extrapolations, the inversion check at m=64, the check order `F_m128_check` and its difference `delta_m128`, and the internal sensitivity `epsilon_internal_abs/rel` (largest of five differences). The source of the table of selected values in the article and of the full table in the supplementary material. Earlier versions of the table are kept in `../validation/previous_tables/` and compared in `../validation/reference_table_versions.csv`. |
| `selected_reference_values.csv` | `generate_latex_tables.py` | The rows of the table of selected values in the article. |

## Audits and diagnostics

Audits quoted in the supplementary material:
`conditioning_audit_full.csv` (`conditioning_audit.py`; condition number of the incoming stable-subspace
matrix at every production transform point), `solver_regression_audit.csv` (`solver_regression_audit.py`;
eigendecomposition versus Schur route), `high_order_spot_checks.csv` (`high_order_spot_checks.py`; orders
128, 192, 256 and their own extrapolation), `alias_correction_exact_audit.csv`, and
`../validation/telegraph_inversion_test.csv` (`telegraph_inversion_test.py`; exact inversion test of the
production series at all 67 lengths).

Retained diagnostics, not used in the article:
`return_integral_audit.*`, `theory_symbolic_checks.json`, `martingale_clock_validation.csv`, `grazing_*.csv`, `flux_return_*.csv`,
`seeded_path_validation_regenerated.csv` (`analytic_limits_symbolic.json` is in `../validation/`).
The short-chain diagnostics (`stiff_*`) and the small-s fits for B (`milne_and_B_convergence.csv`,
`B_*`) were computed with the eigendecomposition route; recomputation with the Schur route changes them
by about 1e-10 relative. Three diagnostic scripts use the uncorrected inversion series with A = 22 (alias
bias about 8e-10, immaterial for them): `refine_stiff_high_order.py` (`stiff_high_order_*`),
`refine_stiff_spectral.py` (`stiff_refinement_*`) and `audit_crossover_intersection.py`.

## Sample-level records

`span_samples/`, `return_samples/`, `heat_path_samples/`,
`grazing_coupled_samples/`: NumPy `.npz` archives of per-chain path functionals (spans,
extrema, endpoints), not full trajectories. Seeds, step counts and chain counts are in the
file names and in the corresponding CSV files.
